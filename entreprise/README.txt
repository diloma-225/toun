TOUN — Espace entreprise — reprise complète

Règles principales :
1. Une formation n’apparaît dans l’espace entreprise qu’après confirmation d’un paiement lié au compte responsable.
2. Sans achat confirmé, l’entreprise est redirigée vers ../formation.php depuis Formations/Affectations/Paiements.
3. Une affectation ne peut utiliser qu’une formation achetée.
4. Une affectation peut être modifiée ou supprimée sans supprimer le collaborateur.
5. Collaborateurs : ajouter avec photo, modifier photo, voir, désactiver, réactiver.
6. Progression : moyenne, en cours, terminées, non commencées, puis détail par collaborateur/formation.
7. Évaluations : lecture des t_quiz et t_resultats_quiz avec notes/statuts.
8. Profil et paramètres ne sont pas dans la sidebar : ils sont accessibles depuis la photo/profil en haut à droite.
9. TOUN AI est intégré dans le menu commun sur toutes les pages.
10. Chaque page garde son CSS dans son propre fichier PHP ; le menu commun porte uniquement le design commun sidebar/topbar/assistant.
